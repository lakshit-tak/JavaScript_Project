# To-Do List

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript with LocalStorage.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using LocalStorage
- Tasks remain saved after page refresh

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
