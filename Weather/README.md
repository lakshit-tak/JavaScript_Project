# Weather App

A simple and responsive Weather application built using HTML, CSS, and JavaScript. It uses a weather API to display current weather information for a selected city.

## Features

- Search weather by city name
- Display current temperature
- Display weather conditions
- Display humidity
- Fetch real-time weather data using an API
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
