# Quiz App

A simple and responsive Quiz application built using HTML, CSS, and JavaScript.

## Features

- Multiple-choice questions
- Display questions and answer options
- Check answers
- Calculate and display the final score
- Move to the next question
- Restart the quiz

## Technologies Used

- HTML5
- CSS3
- JavaScript
